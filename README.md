# SmoKehouse | Restaurant Landing Page

A responsive landing page for a grill and BBQ restaurant, with a working menu filter, a validated reservation form, and a mobile-friendly layout.

**Live demo:** https://ahmadibraheem555.github.io/Restaurant/

> This is a front-end demo project. The names, prices, reviews, and contact details are sample content, and the forms do not send data to a server.

## Features

- Responsive, mobile-first layout built on the Bootstrap 5 grid
- Fixed navigation bar with scroll highlighting and a mobile menu that closes after selection
- Menu section with Breakfast, Lunch, and Dinner filters (vanilla JavaScript)
- Reservation form with field validation, inline error messages, and a confirmation message
- Newsletter form with email validation
- Sections for hero, features, about, menu, reservation, team, and reviews
- Accessibility basics: form labels, visible focus states, skip link, and reduced-motion support

## Tech Stack

- HTML5
- CSS3 (custom styles with CSS variables)
- Bootstrap 5.3
- Vanilla JavaScript
- Font Awesome icons and Google Fonts (Nunito, Pacifico)
- Hosted on GitHub Pages

## Project Structure

```
Restaurant/
├── index.html    # page markup and form logic
├── style.css     # custom styles
└── imgs/         # images used by the page
```

## Run Locally

No build step is needed.

1. Clone the repository:
   ```
   git clone https://github.com/ahmadibraheem555/Restaurant.git
   ```
2. Open `index.html` in your browser.
